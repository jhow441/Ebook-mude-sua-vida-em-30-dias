# Projeto 30 Dias — Organize sua Vida

Versão web interativa (celular e computador, sem instalar nada).
Marcações e respostas ficam salvas no navegador de quem usa (armazenamento local; nada é enviado a servidor).

- `index.html` — o aplicativo
- `img/` — imagens
- `pdf/` — e-book final (leitura), PDF interativo, versão para impressão e planners e extras
- `RELATORIO_AUDITORIA_FINAL.md` — auditoria, correções e checklist de testes da versão V3

Publicado com GitHub Pages: https://jhow441.github.io/Ebook-mude-sua-vida-em-30-dias/
